# Elitloppslördag Games – TV Scoreboard

En fullskärms scoreboard i Elitloppet-stil för hemma-party med 3 lag och 5 grenar.

## Kom igång

```bash
npm install
npm run dev
```

Öppna http://localhost:5173/ och använd **Helskärm** för TV.

## Design

- Vit canvas med **Elitloppet-rosa** (#E6007E)
- Bulkig typografi (Fredoka + Nunito)
- Rosa nummer-cirklar, bento-kort och pill-knappar

## Funktioner

- Poäng per gren med automatisk placering
- Totalställning med tie-hantering
- Klickbara poängceller
- localStorage (behåller data från tidigare "Hemmakampen"-version)
